# FTC Academy KZ

FTC робототехникасын қазақ тілінде үйренуге арналған оқу веб-құралы. React, TypeScript және Vite қолданылды. Басты бет, FTC Hardware модулі және FTC Programming бөлімінің төрт сабағы бар. Robot Simulator карточкасы алдағы модуль ретінде белгіленген.

## Жергілікті іске қосу

Node.js 22.12 немесе одан кейінгі нұсқасы және npm қажет. Терминалды жоба қалтасында ашып, орындаңыз.

```sh
npm install
npm run dev
```

Браузерде терминалда көрсетілген мекенжайды ашыңыз. Әдетте ол http://localhost:5173.

## Өндірістік нұсқа

```sh
npm run build
npm run preview
```

Құрастыру алдымен TypeScript типтерін тексереді. Дайын файлдар `dist/` қалтасына жазылады. `preview` командасы сол нұсқаны жергілікті шолуға мүмкіндік береді.

## FTC Programming · 1-сабақ

**FTC SDK және OpMode негіздері** — бастапқы деңгейге, шамамен 9-сыныпқа арналған сабақ.

Басты беттегі **FTC Programming → Сабақтарды ашу** сілтемесін немесе бүйірлік мәзірдегі **Бағдарламалау** тармағын таңдап, тізімнен 1-сабақты ашыңыз. Тікелей мекенжай: `http://localhost:5173/#programming/sdk-opmode` (порт терминалда көрсетілген мәнге сәйкес болуы керек). Қолданыстағы hash-навигация пайдаланылды.

Сабақта оқу мақсаттары, төрт теория бөлімі, TeleOp/Autonomous салыстыруы, Java тіліндегі толық `HelloFTC` мысалы, бес ұғымды сәйкестендіру және бес сұрақтық тест бар. Java мысалы Gamepad-тағы A батырмасының күйін Telemetry арқылы көрсетеді; моторларды басқармайды. Бұл браузердегі тапсырмалар роботты басқармайды және нақты робот симуляциясы емес. Java мысалы FTC SDK жобасында орындалуға арналған, веб-бетте орындалмайды.

Аяқтау шарттары:

1. Төрт теория бөлімін оқып, «Оқыдым, түсіндім» деп белгілеу.
2. Бес ұғымды дұрыс сәйкестендіру.
3. Барлық бес тест сұрағына жауап беріп, кемінде 4/5 жинау.
4. «Сабақты аяқтадым» батырмасын басу.

Тестте алғашқы таңдалған жауап бекітіліп, түсіндірме бірден көрсетіледі. «Тестті қайта бастау» тек тест жауаптары мен аяқталу белгісін тазартады; оқу белгілері мен сәйкестендіру сақталады. Прогресс `localStorage` ішінде `ftc-academy-kz:programming:sdk-opmode:v1` кілтімен сақталады және Hardware прогресінен бөлек. Сақтау бұғатталса, сабақ жұмысын жалғастырып, ескерту көрсетеді. Прогресс осы браузер мен осы сайт мекенжайына тиесілі; басқа құрылғыға көшпейді.

## Тексеру

Node.js 22.12+ қолданыңыз (тест командасы Node.js-тің TypeScript type stripping мүмкіндігін пайдаланады).

```sh
npm run typecheck
npm test
npm run build
```

Автоматты тесттер: аяқтау шегі (барлық жауап және кемінде 4/5), жарамсыз сақталған деректер, сақтау/жүктеу, бұғатталған сақтау мен квота қатесі, тестті қайталау. Қосымша тест кітапханасы қажет емес.

Қолмен тексеру:

1. Сабақты карточка мен мәзір арқылы ашып, «Оқу бағыттарына қайту» сілтемесін тексеріңіз.
2. Дұрыс және қате сәйкестендірулерді таңдап, түсіндірмесін қараңыз. Tab және бағыттау пернелерімен таңдауды сынаңыз.
3. Тестте қате жауап беріңіз: дұрыс жауап пен түсіндірме бірден көрінуі тиіс. Барлық бес сұраққа жауап бермей аяқтау ашылмауы керек.
4. Шарттарды орындап, сабақты аяқтаңыз. Бетті жаңартыңыз: оқу белгілері, таңдаулар, нәтижелер және аяқталу белгісі сақталуы тиіс.
5. Тестті қайта бастаңыз: теория мен сәйкестендіру сақталып, аяқталу белгісі алынуы тиіс.
6. 400 px мобильді экранда мәтін, тапсырмалар мен мәзірді тексеріңіз; код блогын көлденең айналдыруға болады.
7. FTC Hardware модулінің бұрынғы бөлімдерін ашып тексеріңіз.

11.11.2026 тексеру нәтижелері: `npm run typecheck` өтті; `npm test` — 5/5 өтті; `npm run build` өтті. Chrome браузерінде production bundle негізіндегі жергілікті HTML арқылы сабаққа кіру, сәйкестендіру, дұрыс/қате жауаптар, 4/5 нәтижесімен аяқтау, жаңартудан кейін қалпына келу және тестті қайта бастау тексерілді. 400 px мобильді көрінісі қаралды. Орта HTTP серверін ашуға рұқсат бермеді (`listen EPERM`), сондықтан Vite dev server арқылы браузерлік тексеру орындалмады. Соңында браузер басқаруы жауап бермегендіктен, Hardware-ге қайту жолының қолмен тексеруі аяқталмады; Hardware файлдары өзгертілген жоқ. Java мысалы ресми құжаттамамен салыстырылды, бірақ нақты FTC SDK/роботта құрастырылып орындалған жоқ.

## FTC Programming · 2-сабақ

**DC Motor (тұрақты ток қозғалтқышы) басқару** бірінші сабақтағы LinearOpMode негіздеріне сүйенеді. Сабақтар тізімі: `/#programming/lessons`; екінші сабақ: `/#programming/dc-motor`. Бірінші сабақтың `/#programming/sdk-opmode` мекенжайы сақталды. Екі сабақта да алдыңғы/келесі сабақ пен тізімге өту сілтемелері бар; аяқталған сабақты қайта ашуға болады.

Сабақ құрамында:

- Төрт теория бөлімі: мотордың жұмысы; Control Hub Motor 0 порты және конфигурация; қуат, бағыт және тоқтату; FTC SDK және жиі кездесетін қателер.
- Motor Control Lab: −1…+1 аралығында 0.05 қадамды пернетақтамен басқарылатын slider, FORWARD/REVERSE radio таңдауы, іске қосу/тоқтату, таңба мен шартты айналу бағыты, жаңаратын Java пәрмендері.
- Бес бос орынды толтыруға арналған Java тапсырмасы және толық MotorBasics.java мысалы. Мотор атауы `motor`; A басылып тұрғанда қуат 0.5, жіберілгенде 0; `finally` ішінде `setPower(0)` бар.
- Бес сұрақтық тест: әр жауапқа дереу түсіндірме, қорытынды ұпай, қайта орындау; барлық сұраққа жауап беріп, кемінде 4/5 жинау керек.

Аяқтау үшін төрт теория бөлімін белгілеңіз, Lab-та моторды нөлден өзге қуатпен іске қосып тоқтатыңыз, Java тапсырмасының бесеуін дұрыс орындаңыз және тесттен өтіңіз. Содан кейін «Сабақты аяқтадым» батырмасын басыңыз. Тестті қайталау тек осы сабақтың жауаптары мен аяқталу белгісін тазартады.

Екінші сабақтың кілті — `ftc-academy-kz:programming:dc-motor:v1`. Бірінші сабақтың `ftc-academy-kz:programming:sdk-opmode:v1` кілті мен деректер пішімі өзгермеді. Hardware прогресіне жазылмайды. Lab-тың қозғалыс күйі сақталмайды: бетті қайта ашқанда мотор тоқтап тұрады. Қуат шектен шықса қысқартылады, жарамсыз/шексіз сан нөлге айналады. Сақтау бұғатталса немесе квота толса, жаттығулар сол сессияда жұмыс істеп, ескерту көрсетеді.

### Көрнекіліктің шектеулері

Lab — мотор физикасының симуляторы емес. Анимацияның қарқыны тұрақты, қуаттан RPM есептелмейді. Қуат таңбасы мен бағыт байланысы RUN_WITHOUT_ENCODER үшін көрсетіледі. FORWARD + оң қуаттың сұлбада сағат тілімен берілуі — шартты таңдау; нақты бағыт қарау жағына, моторға және қосылымға байланысты. Нақты жылдамдыққа мотор түрі, жүктеме, батарея кернеуі және басқа жағдайлар әсер етеді.

Stop көрнекілікті бірден тоқтатады; нақты механизм инерциямен қозғала алады. BRAKE нөлдік қуатта айналуға кедергі келтіреді, позицияны дәл ұстайтын реттегіш емес. Бет Java кодын құрастырмайды, роботпен байланыспайды. Java мысалы нақты FTC SDK/роботта компиляцияланып орындалған жоқ. `prefers-reduced-motion` қосылса, айналу анимациясының орнына бағыт мәтіні қалады.

## FTC Programming · 3-сабақ

**Gamepad (ойын контроллері) және TeleOp (оператор басқаратын режим)** екінші сабақтағы мотор басқаруына сүйенеді. Сабақтар тізімінен 3-сабақты таңдаңыз немесе `/#programming/gamepad-teleop` ашыңыз. Алдыңғы екі сабақтың URL-дері мен сақтау пішімдері өзгермеді. 2-сабақтан 3-сабаққа келесі сілтеме, 3-сабақтан 2-сабаққа алдыңғы сілтеме бар. Іске аспаған сабаққа сілтеме жоқ.

Сабақ құрамында төрт теория бөлімі (Gamepad/Driver Station, режимдер, Joystick Y, басқару циклі), Gamepad Lab, бес Java бос орын тапсырмасы, толық GamepadMotor.java мысалы және бес сұрақтық тест бар. Қазақша түсіндірмелер, алғашқы қолданыста термин түсіндірмелері және дереу кері байланыс берілген.

### Gamepad Lab басқаруы

- Тетікті тінтуірмен немесе саусақпен тік бағытта сүйреңіз. Pointer Events пен pointer capture қолданылады. Жіберу, pointer cancel немесе capture жоғалуы тетікті ортаға қайтарады.
- Tab арқылы тетікті таңдаңыз: ↑ Y-ті 0.10-ға азайтады, ↓ арттырады; Home −1, End +1; Space немесе Escape нөлдейді. «Алға»/«Артқа» батырмалары −0.50/+0.50 мәнін орнатады; «Нөлге қайтару» оларды нөлдейді.
- Перне/батырма мәндері зерттеу үшін сақталады; тетіктен фокус кетсе, терезе фокусы жоғалса немесе бет жасырылса нөлденеді. Қозғалыс күйі localStorage-ға жазылмайды.
- Мәндер −1…+1 шегінде: `power = -gamepad1.left_stick_y`. Қуат жолағы нөлден екі жаққа таралады, таңба, сан, шартты бағыт және Java-дағы есептелген пәрмен көрінеді. Мысалы, Y = −0.50 → power = +0.50.
- Lab — нақты құрылғыға қосылмайтын оқу моделі. Тұрақты анимация қарқыны RPM білдірмейді. Нақты жылдамдық моторға, жүктемеге, батареяға тәуелді; сағат тілі бағыты шартты. Reduced-motion стилінде айналу анимациясы өшіріледі.

### Прогресс және аяқтау

## FTC Programming · 4-сабақ

**Autonomous (автономды режим) негіздері** алғашқы үш сабақты жалғастырады. Бағдарламалау тізімінен 4-сабақты таңдаңыз немесе `/#programming/autonomous` ашыңыз. Алғашқы үш сабақтың маршруттары, прогресс кілттері және пішімдері сақталды. Сабақ тізімі мен алдыңғы/келесі сілтемелер тек іске асқан төрт сабаққа бағыттайды.

Сабақта оқу мақсаттары, төрт теория бөлімі, үш Path Lab тапсырмасы, алты Java бос орны, толық бір моторлы Autonomous LinearOpMode мысалы, барлық 32 бос емес код жолының қазақша түсіндірмесі және бес сұрақтық тест бар. Мазмұн: Autonomous/TeleOp, алдын ала берілген алгоритм, @Autonomous, START/STOP, уақытпен басқару, Encoder кері байланысы, жоспарлау және debugging.

### Autonomous Path Lab

6 × 6 тор: x оңға, y жоғары өседі; координаталар 0–5. Бастау, нысана, роботтың алдыңғы жағы және жүрілген жол бөлек белгіленген.

- **Алға / Move Forward:** робот қарап тұрған бағытта дәл 1 ұяшық.
- **Солға 90° / Turn Left 90°**, **Оңға 90° / Turn Right 90°:** тек бағыт өзгереді. Бұрылу анимациясы да 90°; 0/360 шекарасында кері 270° айналмайды.
- **Тоқтау / Stop:** тізбекті аяқтайды; одан кейінгі пәрмендер орындалмайды. Тапсырма нысанада Stop орындалғанда есептеледі. Нысанаға алғаш жеткенде де кері байланыс беріледі.

Үш тапсырма: (1) түзу жол, (2) бір бұрылысы бар жол, (3) кедергіні айналып өту. Шекарадан шығу және сұр кедергіге кіру бұғатталады; робот соңғы жарамды орында қалады. Тексерілген пәрмен санағы бұғатталған әрекетті де қамтиды; кері байланыс оның орындалмағанын түсіндіреді.

Пәрменді қосыңыз; ↑/↓ арқылы ретін өзгертіңіз, × арқылы жойыңыз. Барлық әрекет native button арқылы тінтуірге, touch және Tab/Enter/Space пернелеріне қолжетімді. Шек — 32 пәрмен. «Іске қосу» әр 700 мс сайын бір пәрменді орындайды. «Кідірту» орынды және қадамды сақтайды; «Жалғастыру» сол жерден жалғайды. «Бір қадам» debugging үшін келесі бір пәрменді орындайды.

Орындалу немесе кідірту кезінде өңдеу бекітіледі. Өңдеу үшін «Бастапқы күйге» басыңыз: робот, жол және санағыш тазарады; тізім сақталады. «Тізімді тазалау» пәрмендерді жояды. Бет жасырылса, автоматты орындалу кідіртіледі. Қайта іске қосу мен түзету аяқталған тапсырма белгілерін өшірмейді. Бетті жаңартқанда тек прогресс сақталады: тізімдер мен қозғалыс күйі сақталмайды.

Бұл — детерминдік оқу моделі. Ұяшық, 90° және анимация уақыты нақты FTC Drivetrain дәлдігін немесе физикасын сипаттамайды. Java мысалы тордағы маршрутты орындамайды.

### Java мысалы және прогресс

TimedMotor.java — бекітілген **бір** моторға 0.3 қуат беріп, sleep(1000) арқылы шамамен бір секундтан кейін қуатты нөлдеу мысалы. @Autonomous, LinearOpMode, hardwareMap.get(), waitForStart(), opModeIsActive(), setPower() және finally тазалауы бар. Бұл толық роботтың жүруі/бұрылуы емес. Уақыт нақты қашықтыққа кепіл бермейді; Encoder дәлдікті жақсарта алады, бірақ сырғанауды жоймайды.

Жеке кілт: `ftc-academy-kz:programming:autonomous:v1`. Төрт оқу белгісі, орындалған үш тапсырманың id-лері, алты Java таңдауы, бес тест жауабы және аяқталу белгісі сақталады. Ұпай сақталған жауаптардан есептеледі. Жарамсыз деректер қалыпқа келтіріледі; storage/quota қатесі сабақтың жұмысын тоқтатпайды.

Аяқтау шарты: теория 4/4, Path Lab 3/3, Java 6/6, тесттің барлық сұрағына жауап және кемінде 4/5; содан кейін «Сабақты аяқтадым». Тестті қайталау тек осы сабақтың тесті мен аяқталу белгісін тазартады. Аяқталған сабақ пен тапсырмаларды қайта ашуға болады.
