# FTC Academy KZ

FTC робототехникасын қазақ тілінде үйренуге арналған басты бет. React, TypeScript және Vite қолданылды. Үш бағыт көрсетілген. Robot Simulator карточкасы алдағы модуль ретінде белгіленген.

## Жергілікті іске қосу

Node.js 22.12 немесе одан кейінгі нұсқасы және npm қажет. Терминалды жоба қалтасында ашып, орындаңыз.

```sh
npm install
npm run dev
```

Браузерде терминалда көрсетілген мекенжайды ашыңыз. Әдетте ол http://localhost:5173.

## Өндірістік нұсқа

```sh
npm run build
npm run preview
```

Құрастыру алдымен TypeScript типтерін тексереді. Дайын файлдар `dist/` қалтасына жазылады. `preview` командасы сол нұсқаны жергілікті шолуға мүмкіндік береді.
